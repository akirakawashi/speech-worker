# Speech Worker

Будущий самостоятельный проект фоновой обработки звонков: получение записей,
сохранение в MinIO, подготовка аудио, вызовы Whisper и LLM, повторы заданий
и передача результатов обработки.

Воркер предназначен для Kubernetes на CPU. Он обращается к серверам моделей
по HTTP; CUDA и доступ к GPU ему не требуются.

Сейчас создана папка с правилами и документацией. Исполняемый код ещё не перенесён:
текущая реализация остаётся в `../whisper-backend/`.
