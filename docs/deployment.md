# Запуск на GPU-сервере

Воркер разворачивается без Kubernetes и вызывает существующий контейнер
Whisper по HTTP. Воркер использует CPU/ffmpeg, GPU использует сам Whisper.
MinIO находится на отдельной машине. GigaAM пока не подключён.

## Настройки и схема

Для новой установки создать `.env` по [.env.example](../.env.example).
Существующий `.env` сохранить. Заполнить адрес общей базы, MinIO, Whisper,
API бэкенда и настройки скачивания Телесейлза. Служебный токен должен совпадать
с `SPEECH_WORKER_API_TOKEN` бэкенда. Ключи LLM, reporting-базы и API списков
Телфина воркеру не нужны. [Настройки](configuration.md).

Нужна схема бэкенда `sp_0017_analysis_storage`. Миграции применяются отдельно;
воркер только проверяет их. Совместимый API поддерживает два маршрута ingest
и приём ASR: [контракт](../../speech-backend/docs/intake-ownership.md).

## Одна команда воркера

```bash
uv sync --locked
uv run --locked speech-worker
```

Или Docker:

```bash
docker compose up -d --build
docker compose logs -f worker
```

Основная команда всегда читает очередь `ingest`/`transcribe`, полосы
`daily,backfill`, одно задание за раз. Она не перечисляет звонки и не
запускает расписания. Для автоматического приёма/анализа/оценки отдельно
работает `speech-process` в проекте бэкенда на CPU.
[Запуск обоих процессов](../../speech-backend/docs/worker-runtime.md).

```bash
uv run --locked speech-worker --once
uv run --locked speech-worker --stages transcribe
uv run --locked speech-worker --lanes daily
```

`--once` обрабатывает не больше одного задания и выходит. Пустая очередь —
успешный выход. `--stages` собирает только выбранные технические ресурсы.
`analyze`/`evaluate` отклоняются. Старые `--sources`/`--queue-only` удалены;
источники автоматического приёма выбираются флагом `--sources` бэкенда.
Ручные `speech-ingest` и `speech-backfill` также перенесены в бэкенд.

## Контейнер и файлы

Compose использует сеть Linux-хоста: `127.0.0.1` Whisper указывает на GPU-сервер.
Для MinIO указать адрес его отдельной машины. UID/GID — 10001; `worker-tmp`
хранит временные файлы. Для `local_export` нужен дополнительный read-only mount
каталога с тем же абсолютным путём, который использует приём бэкенда.
Для `sequence`/`reporting_view` достаточно HTTP-доступа NCC — отчётная база
подключается только бэкендом. Аудио и рабочий `.env` в образ не включаются.

## Остановка и переключение

SIGTERM/SIGINT прекращает новые захваты, текущая работа заканчивается,
пул закрывается. Compose даёт 35 минут до принудительной остановки.

```bash
docker compose stop worker
```

Локальные файлы очищаются после успеха/обычной ошибки/отмены. При следующем
старте оставшиеся собственные каталоги удаляются только после проверки
файловых блокировок. Исходник в MinIO сохраняется до отдельной политики хранения.
Буфер ASR переживает перезапуск без WAV: [доставка](transcription-delivery.md).
Внутреннюю очистку контейнера Whisper ещё нужно проверить на сервере.

Перед выпуском остановить прежние обработчики и таймеры этой базы, дождаться
активных заданий и согласованно обновить API, CPU-процесс и воркер. Одной
ревизии схемы недостаточно: старый `worker-plan` удалён. Новые миграции для
этого переноса не нужны. Сервер в рамках рефакторинга не переключался.
