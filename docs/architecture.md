# Архитектура воркера

Решение владельца 11.10.2026: воркер — самостоятельный репозиторий
`speech-worker` с независимой сборкой и развёртыванием в Kubernetes на CPU.
Сейчас работаем с ним и `speech-backend`; фронтенд отложен.

## Ответственность и ресурсы

Воркер получает записи источников, сохраняет оригиналы в MinIO, подготавливает
аудио, вызывает Whisper и LLM по HTTP и передаёт результаты обработки.
Очередь обеспечивает доставку заданий и возможность повторного выполнения.

CPU нужен для ffmpeg и прикладной обработки, память и временный диск — для файлов.
Вычисления моделей выполняют отдельные сервисы на GPU-сервере. Воркеру не нужны
CUDA, GPU или установленные движки моделей.

Бэкенд и воркер связываем явными версионируемыми контрактами заданий и результатов.
В заданиях передаём идентификаторы и ссылки на данные; записи хранятся в MinIO.
Проект должен собираться без исходников соседнего репозитория.

Конкретный транспорт очереди, контракт результатов и владение таблицами
определяем при реализации разделения. Создание папки не меняет действующий
конвейер или политики обработки звонков.

## Слои

| Пакет | Ответственность |
|---|---|
| `src/presentation` | Обработчики заданий и CLI, валидация входа |
| `src/application` | Сценарии, DTO и порты внешних операций |
| `src/infrastructure` | Очередь, источники записей, MinIO, ffmpeg и HTTP-клиенты |
| `src/domain` | Правила обработки и допустимые переходы |
| `src/setting` | Pydantic Settings |
| `src/di` | Сборка зависимостей и время жизни ресурсов |

Presentation вызывает application; application применяет domain и использует
порты. Infrastructure реализует порты, DI внедряет реализации.
Application не импортирует infrastructure; domain не зависит от других слоёв.
Через границы передаём Pydantic DTO; транспортные объекты остаются в адаптерах.

Цикл очереди отвечает за техническое исполнение. Выбор следующих этапов и
решения о состоянии звонка принадлежат application и domain.

## Состояние перехода

Папка пока содержит документацию и правила. Исполняемый код и окружение остаются
в `whisper-backend`; Git-репозиторий не инициализирован. Переносим законченные
сценарии с проверкой повторов, остановки и конкуренции воркеров.

Обезличивание текста не возвращаем. Оценка продаж предназначена только для
Телфина; NCC в неё не входит.
