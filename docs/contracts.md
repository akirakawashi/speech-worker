# Контракт разделения 1.0

Дата выделения: 12.10.2026. Зафиксирован существующий формат взаимодействия
через PostgreSQL; новый брокер, HTTP API воркера и новые этапы не добавлены.

## Схема и владение

- База речи общая с speech-backend, адрес задаёт SPEECH_MS_DATABASE_URL.
- Миграциями и изменением схемы владеет speech-backend. Воркер не содержит
  своей копии Alembic и не запускает миграции.
- Требуемая ревизия: sp_0015_drop_masking.
- Воркер пишет результаты обработки в существующие таблицы речи;
  API читает их и управляет пользовательскими настройками и доступом.
- Рабочие секреты каждого проекта настраиваются отдельно.

## Задания

DTO очереди: [NewJob и ClaimedJob](../src/application/ports/queue.py).
Этапы: ingest, transcribe, analyze. Полосы: daily и backfill.
В payload передаются JSON-данные задания; бинарное аудио хранится в MinIO.

Сохраняются UUID звонка и задания, попытки, lease, run_after, priority и
метка not_before. Следующий этап наследует полосу и приоритет звонка.
Срочность сохраняется: свежие NCC — 0, отложенные NCC — 10,
Телфин — 20, история — 100.

Версия 1.0 обозначает договорённость в документации. Поле версии в существующий
payload не добавлялось, поэтому уже поставленные задания читаются без конвертации.
Изменение DTO или значений enum требует проверки совместимости обоих проектов
и обновления этой договорённости перед выпуском.

## Результаты и повторы

Результат этапа, завершение задания и постановка следующего фиксируются
в одной транзакции. Сеть, ffmpeg и вызовы моделей выполняются вне неё.
Просроченная аренда запрещает записывать устаревший результат.

Повторная запись расшифровки заменяет её целиком. Изменение реплик или ролей
снимает связанную оценку согласно существующим правилам. Текст хранится
без обезличивания; оценка продаж применяется только к Телфину.

Общий транспорт Whisper сохранён; конвейер использует SPEECH_WHISPER_*,
verbose_json и сегменты с таймкодами. Замена транспорта не должна менять
[DTO распознавания](../src/application/dto/transcription.py).

## Независимость проектов

Воркер не импортирует исходники соседнего проекта. Общие DTO и enum перенесены
как локальная версия текущего контракта. Новые изменения форматов согласуются
через контракт и тесты, а не через runtime-импорты из speech-backend.

Существующие исходники сохранены. До переключения запусков нельзя одновременно
включать старые и новые таймеры приёма/оценки для одной базы: это разные точки
запуска одних и тех же фоновых сценариев.
